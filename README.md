# Restaurant Reservation and Table Management System

**MCA Web Development Project**

## Project Overview
The Restaurant Reservation and Table Management System is a web-based application that allows users to explore restaurants, view menus, select tables, and book reservations online.

The system also provides administrative features to manage reservations and monitor table availability.

## Features
- User Login and Registration
- Restaurant Details and Menu
- Online Table Reservation
- Date and Time Selection
- Table Category and Selection
- Special Requests
- Booking Confirmation
- My Bookings
- Admin Dashboard
- Reservation and Table Availability Management

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS
- Node.js
- Express.js
- MongoDB

## How to Run the Project

### Frontend
```bash
npm install
npm start
```

### Backend
Open the Server folder in a separate terminal and run:

```bash
npm install
npm start
```

*Note: Backend commands may vary depending on the scripts defined in the Server/package.json file.*
